# 知识库维护

知识库是整个 `D:\mfa_files`。当前将它理解为“我们自己的 Wiki”：用户和 AI 都参与维护，也都使用它学习和查找；未来可能有其他读者。库中的内容是多样的，包括原始论文等文件、音视频转写、网页、经过阅读或修改的笔记，以及其他实际需要保留的内容。这里保存帮助 Wiki 逐步形成关联的工具与实验记录，原有知识文件仍在原位。

当前出链只处理正文到词条页面的链接。先根据材料理解需要选择概念，再结合含义、范围、别名和页面用途判断终点，名称相同或材料中有相关讲解都不足以确认目标。缺少目标时可以先保留链接；优先创建的候选结合内容价值和当前需要安排。2026-10-05，用户明确此前“五个”的限制可以改变，现不再将其作为数量上限，出链说明已同步更新。已选概念每次正文出现都出链，终点一致。前三篇尚保留审核时的“首次引入、定义和关键解释处链接”版本，逐次重复标记尚未回补。此前补齐了五个终点，原七份材料保持不变，没有递归创建其他词条。

用户已确定链接方向：维护的正向概念链接从正文到独立词条页面，反向查阅可以定位到来源中的具体文字。独立概念不以另一个词条的小节作为正向终点。上下层词条各有页面：上层解释整体，下层展开具体概念的细节；相关但不同的概念各自讲清范围和区别。低阻力仍是总体原则，页面分工、反向位置如何自动派生与实际讲解范围正在信息流实验中继续讨论。

词条围绕主题自身形成有内容、可独立阅读的讲解，各小节根据主题组织，不能用一串相邻概念和链接代替正文。当前试验不要求首次写作就覆盖主题的重要方面，而是从当次材料支持的内容开始，保持已有解释连贯，逐步完善。此前对重心、难度和阅读体验的讨论仍可帮助判断，但不固定篇幅、栏目或关系层级。别名只收完全同义表达，正文沿用词条出链方法，排版保持可读并使用 Obsidian 数学格式。外部参考与相关资料呈现暂缓。

用户认可持续发现链接的补充方向：内容变化后重新检查，词条新增或实质变化后回查旧内容，逐批回看未变化的旧材料，并由系统记录检查覆盖情况。名称及别名的明确提及与需要理解语义才能发现的隐含关系分别处理。这是共同认可的设计方向，尚未实现，也不纳入本次只解释首次词条出链的成果文档。

## 运行与维护

本机已在本目录 `.venv/` 建好 Python 环境。在 PowerShell 中运行：

```powershell
& 'D:\mfa_files\knowledge-maintenance\run-mac.ps1'
```

要完整重建可加 `-Rebuild`。命令只读 MAC 原文与本轮已有的选定词条讲解，更新 `index.json`、`verification.json` 和 `检查报告.md`。词条清单来自本轮 AI 阅读选择，保存在 `concepts-selection.json`；程序复核出处、记录正文提及、课程对词条的引用及词条讲解中的引用，不生成课程间互链。原文变化后，如果提取依据消失，命令会报告问题，需重新阅读判断。定时自主语义抽取尚未实现。

当前单篇追加与日常检查是独立命令。`link_concepts.py`先保存原始字节副本和编辑预览，`--apply`只应用该预览；原文自预览后变化则拒绝操作。已存在“相关词条”区时，不自动重建或覆盖。它目前用于共同讨论后的小范围试验，不是批量改写课程的默认入口。具体记录见本轮说明。

迁移或运行环境丢失时，先确保 Python 可用，在本目录执行：

```powershell
python -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install -r requirements.txt
& '.\run-mac.ps1'
```

行为检查：`& '.\.venv\Scripts\python.exe' -m unittest discover -s tests -v`。运行位置为本目录。测试在临时资料上进行，不修改真实知识文件。

上述早期分析命令以 SHA-256 内容哈希判断是否需要重新解析，新增、修改和移出范围会被记录，重命名暂呈现为新增加移出。每轮重新计算引用，使旧页面能找到新出现的词条页。当前小知识库已接入 Git/GitHub，变化识别明确使用 Git；它与这些早期只读分析命令分开。自动增量维护和夜间调度尚未接通。

## 工作方式

每轮先说明计划和想法，与用户讨论，然后实现、验证、请用户体验、调整。用户可以随时改变计划。需要人工判断、体验或操作时，明确提出具体要求。阶段性产物不代表长期目标已经完成。

知识仍以普通本地文件保存。Obsidian 是现有阅读与编辑入口。维护工具生成的索引、检查和候选关联与原始内容分开保存，均应可以重建。

源文件编辑须有具体、可查看的范围。先前实验做过单篇文末追加，当前小知识库实验已改为正文词条链接，并用独立 Git 审阅索引核对修改边界。确定性引用和语义判断要区分；提取应有原文依据，不把词语同时出现直接当成词条之间的知识关系。方法更新与正文实际执行状态需要分别说明。
