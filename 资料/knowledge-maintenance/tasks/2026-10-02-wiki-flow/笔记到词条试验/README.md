# 笔记到词条：自动微分维护试验

本轮已由用户明确开始。主要观察词条是自动微分，材料范围为小知识库 MAC0101—0105。先按文件次序阅读，每篇分成保持上下文完整的块；不在完成并保存当前块的处理之前读取下一块。

各词条的信息来源都是实际引入的笔记。词条间链接用于查阅，不驱动相互改写，也不作为生成新内容的来源。同一块笔记可以分别帮助几个词条，是否修改、吸收多少和怎样讲述分别判断。原文无合适标注词时，在对应段落后或小节末集中一行补充链接。

本目录单独试验，原小知识库、旧五篇词条及上轮梯度下降试验保留。本轮从没有正文的状态逐步形成页面，不用旧词条作为写作材料。课程此前已经被阅读过，本次模拟落实在输入的逐次打开、处理与保存，不宣称材料是首次见到。

## 当前计划

1. 按顺序读取一块笔记，保存原始片段。
2. 解释它提供了什么，判断对主要观察词条及邻近概念的不同贡献。
3. 修改有实际贡献的页面；已经覆盖、不适合本页或没有依据时可不改。
4. 在试验笔记中标记有明确词语的入口，附近集中呈现无直接标注词的关联。
5. 记录本次判断，保存完整词条状态，再读取下一块。
6. 全部材料处理后，核对来源、版本、链接位置和演算，交给用户阅读。

## 文件入口

- 输入/：本轮实际读取的原文片段，按步骤保存。
- 词条/：当前词条，内容只来自已经引入的笔记及理解它所需的解释。
- 笔记/：只包含已处理部分的课程副本，最后形成五篇带本轮链接的材料。
- 过程/：每步具体判断、修改位置与版本入口。
- 版本/：每步完成后的完整词条状态，旧版本不回写。
- 流程.py：只负责逐步读取、保存和版本核对，不作语义判断或自动写文章。
- 状态.json：操作脚本生成的步骤与哈希记录，用户无需手工维护。
