# 词条发现、正文出链与页面建立

一篇材料进入 Wiki，或已有材料的内容发生变化后，需要理解两件事：读者会需要查阅哪些概念，这份材料又能帮助哪些词条获得更好的讲解。前者影响正文中的链接，后者影响页面的建立与完善。两者互相提供线索，但不一定得到相同的名单。

词条随着笔记提供的信息逐步形成。材料给出有价值的内容，就可以用它形成第一版，或与已有讲解融合；不要求先完成一篇完整百科文章。正文链接让读者从当前材料进入独立讲解页，尚无页面时也可以先保留入口。

本说明介绍怎样理解材料、发现词条、选择名称、建立正文链接，以及判断页面是否值得建立或完善。这里的“笔记”包括本轮实际读取的课程材料等内容；其他来源也可以提供信息，具体读取方式另行处理。本说明只讨论词条关系，不涉及前后章节、项目计划、原始资料等其他出链。词条正文的具体写法与整库自动维护另行讨论。

以下描述截至 2026-10-05 的共同认识。处理时仍以实际内容、阅读体验和低阻力为依据，不分配固定栏目、数量或关系层数。

## 1. 理解材料，再选择正文中值得查阅的概念

先读懂当前材料讲什么、解释什么问题，以及读者理解它需要哪些基础。选择正文概念时，不先用知识库已有页面限制范围。某个词条已经存在，不会自动使它值得链接；尚无页面，也不妨碍正文先引出它。

值得出链的概念，会一定程度影响本文理解，并有进一步解释的价值。它可以是文章的中心，也可以是理解中心内容所需的基础、文中明确区分的对象，或者影响结论的条件。判断时可以考虑：不了解它，读者是否会难以跟上这一段的表达或推理？从这里进入讲解页，能否帮助当前阅读？

例如，一篇解释神经网络怎样学习的文章，通常需要模型训练、损失函数、梯度下降等过程和机制的入口，也可能需要向量、矩阵、模型参数等基础概念的入口。开头顺带列举的模型，如果后文没有展开、理解本文也不依赖逐一了解，就未必都需要标记。换一篇材料，它们的地位又可能不同。

目标是覆盖本文所有值得链接的内容，同时让人能顺畅读下去。密度主要通过选择概念来把握：中心内容和必要基础应得到覆盖，帮助很小的顺带提及可以保留原样。既不分配固定出链数量，也不因为一个词可以在百科中找到解释就自动选入。

## 2. 从笔记中发现能够帮助完善词条的信息

正文概念提供直接线索，但材料的贡献可能超过它明确写出的词名。一个机制、用途、区别、计算例子或适用条件，都可能帮助某个词条发展。阅读时需要理解这些内容，而不是只匹配名称。

同一段笔记可以帮助几个词条，各页吸收的部分和讲述方式不同。例如，一段材料讲“计算损失关于参数的梯度，再按一定幅度更新参数”：

| 可能受益的词条 | 这段内容对本页的贡献 |
| --- | --- |
| 模型训练 | 解释参数更新在训练过程中的位置和作用 |
| 梯度下降 | 解释当前梯度怎样参与更新、方向怎样确定 |
| 学习率 | 解释控制调整幅度的量怎样影响一次更新 |

即使原文没有直接写出“学习率”，实际讨论调整幅度的内容也可能帮助完善它。维护者围绕各页主题理解材料，不将同一段讲解复制到几处。某页已经覆盖相应内容时，可以不改。

直接相关的信息优先考虑，近邻概念的内容也可能很有价值，关系更远时结合重要性取舍。这里的远近是判断线索，不需要精确计算层数。最终仍要看新信息放进目标页是否有用、自然，是否围绕它自身的主题。候选范围可以较广，实际改动逐页判断。

信息来源始终是实际引入的笔记。词条之间可以建立查阅链接，但不互相作为内容更新的来源；新词条或新链接出现后，不据此自动改写其他词条、继续生成更多知识。同一段笔记可以分别帮助多个页面，处理每页时都回到这段笔记及该页现有讲解，判断它的实际贡献。

维护者可以理解、推导和组织笔记中的信息，补足必要解释。对未直接点名的关联，应能说明原文提供了什么、它怎样帮助目标词条，不以名词联想代替内容依据。词条之间的关联用于帮助查找，新增内容仍由笔记支持。

## 3. 确认概念范围、名称与已有页面

词条需要有清楚的含义，适合独立查阅。粒度取决于概念的实际区别，不按每段一个、每节几个来分配。

例如，反向传播负责计算梯度，优化器使用梯度更新参数。两者共同参与训练，却承担不同作用，应分别判断页面范围。上下层概念也可以各有页面：上层解释整体，下层展开具体机制。维护的正向词条链接通向独立页面，不以另一页的小节代替；反向查阅则可以定位到来源中的具体文字。

正文用词和页面名可以不同。保留原文措辞，选择清楚、常用、能表达范围的词条名。名称不必包含课程编号，也不必将所有中英文表达堆进文件名。例如，正文的“参数”在模型语境中可以指向“模型参数”，“状态”可能指向“训练状态”。名称明确时保持简洁，有歧义时再补充语境。

同义表达应共用目标，中英文名称及缩写都可以帮助识别，但别名必须表示同一个概念。只是相关、范围更大或更小的概念不能当作同义名称；相同字面在不同语境中也可能有不同含义。

选择概念后，再寻找已有终点。名称、别名和搜索帮助定位候选，随后需要阅读页面，确认含义、范围和用途是否合适。只看同名、发现某页有相关段落，或者找到一篇恰好讲过该概念的课程文件，都不足以认定词条终点。

已有同一概念的页面，即使内容尚不充分，也可以继续完善，不因讲解较薄而另建重复页。相关但不同的概念保持各自范围。同名异义或对应关系不清楚时，先明确问题，不用一个看似接近的页面凑成终点。

暂时没有合适页面时，可以先使用经过判断的名称建立无目标链接。是否现在建立页面，还要结合笔记能提供的信息和当前需要判断。

## 4. 在正文中标记，并把补充链接放在对应内容附近

原文有合适词语时，以它作为点击位置。Markdown 可以使用 Wiki Link，即双括号形式的页面链接：

```markdown
这个过程叫 **[[梯度下降]]**。
一个 [[训练步|training step]] 通常包含前向传播、反向传播和参数更新。
```

这里的 training step 指训练步。竖线左侧是目标页面，右侧是显示的原文；这种写法保留作者原来的表达，也让同义名称连接同一概念。

一个概念被选中后，在正文中以同一含义多次出现时，每次都建立链接，目标保持一致。不因前文已经链接过就省略后面的提及。后文改用同义名称时，仍指向同一目标；字面相同但含义变化时，需要重新判断，不能只作全文字符串替换。

原文没有可以直接标注的词语，但这一块内容确实与某个词条相关时，在相应段落后或小节末单独列出。例如：

```markdown
相关词条：[[梯度下降]]、[[学习率]]
```

同一块内容的这类补充链接集中一处，放得足够近，让人能判断它们关联哪段文字；不集中搬到全文末尾，也不在每句话后插入一行。选择自然的段落边界，避免打断公式、推导或连续解释。没有这类关联的内容，不必增加空的“相关词条”行。

链接行用于呈现原文没有合适点击位置的关联，不代替正文中已有词语的标记，也不借它补写原文没有提供的新知识。是否需要简短解释关联，结合实际阅读判断；链接应让人看得懂，又不抢占主线。

尽量保留原文、强调样式和段落结构。公式、代码和已有链接需要正常使用，通常在邻近的自然语言说明或补充链接行提供入口，不将普通 Wiki Link 插进公式符号或代码变量。可正常承载链接的正文文字仍按逐次标记处理，特殊格式随材料判断。

阅读过密时，重新检查是否选入了对本文帮助很小的概念，以及补充链接的位置是否合适；不能仅凭链接数量判定效果。

## 5. 判断页面的建立、复用与继续完善

找到终点之后，仍要判断笔记对这个页面有什么贡献。出链完成不等于页面维护完成，缺少目标也不意味着立即为每个链接生成一个文件。

对尚无页面的概念，考虑材料是否支持一版有用的讲解。哪怕目前只覆盖这个概念的一个方面，也可以成为页面起点；内容范围应清楚，后续随笔记扩展。不要求第一版写成完整百科文章，也不把创建空文件当作完成了一次讲解。

如果材料只是提到一个名字，没有提供值得进入该词条的信息，可以先保留无目标链接。重要页面也可以另行安排学习和整理，但这与从本次笔记吸收信息是不同的工作，应说明实际依据。页面建立不必全部在首次出链时完成。

对已有合适页面的概念，复用链接目标，同时阅读其现有内容。新笔记可能只补充一句、提供一个例子、改变某段解释，或带来需要重新组织的认识；已经覆盖的内容可以不改。内容有冲突时，需要保留和说明不同说法及条件，不能无依据覆盖。这份说明明确需要作这些判断，不规定融合时的栏目、篇幅和具体写法。

一份笔记可以直接帮助多个页面，各页分别取舍。例如神经网络材料中的向量表示，可以帮助向量词条解释一种用途；训练流程则可能帮助模型训练词条。不能因向量不是本文中心就一律不考虑，也不能因两者有关就把整套神经网络知识放进向量页。

哪些页面值得优先发展，结合信息价值、当前学习需要和实际工作安排决定。不预设五个或其他固定上限，不要求凑数量，也不因候选较多就全部创建。已有页、新页，以及正文未直接点名但受到笔记帮助的页面，都看各自的实际贡献。数量与顺序可以随使用调整。

维护记录应能说明处理了什么、为什么改或不改，以及改动落在哪里。详细程度随任务需要安排，不要求用户为每个词填写表格、手工维护双向链接或逐项审批机械操作。

## 6. 核对结果并保留继续完善的空间

处理后沿着笔记和受影响页面阅读一遍，检查：

- 中心概念、必要基础和关键区别是否得到适当入口，是否遗漏影响理解的内容。
- 已选概念的各次提及、同义名称和目标是否一致，同名异义是否区分。
- 页面范围是否通过内容确认；原文、公式、代码和格式是否保留。
- 没有合适正文词语的关联，是否在对应内容附近集中呈现，能否顺畅读过。
- 各词条的变化是否由笔记支持，是否围绕自身主题，是否出现重复讲述或不必要的扩展。
- 新页是否承载本次实际形成的内容；暂未建立的目标和决定不改的页面是否按真实状态说明。

阅读与内容判断优先，解析检查帮助发现格式和引用问题，但不能证明文字好读、语义关系全面。

以后出现新笔记或新的理解，选择、链接和讲解都可以继续完善。词条建立后仍接受笔记的信息；词条之间的新链接提供查阅入口，不作为额外的信息来源。相关认识发生变化时，方法说明本身也需要重新审视。

单词条逐步融合已有试用；多词条分别吸收笔记信息、补充链接的阅读效果和整库自动运行仍需实践。这里描述处理方向，不表示这些能力已经由程序实现，也不替代实际阅读后的调整。
