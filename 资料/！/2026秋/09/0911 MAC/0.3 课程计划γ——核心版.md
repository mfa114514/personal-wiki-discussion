
# Modern AI Core
## 现代人工智能核心课程总纲

> 课程定位：以现代人工智能的核心模型、学习原理、训练方法与研究实践为主线，系统建立从神经网络基础机制到 Transformer、GNN、生成模型、LLM、多模态模型的统一认识。
>
> 本课程不是“AI 应用大全”，也不以特定领域应用为章节组织方式。生物、医学、图结构数据等内容只在其能够体现重要 AI 方法时作为实例出现。
>
> 课程默认允许直接进入数学推导和模型原理，不人为降低理论难度。遇到所需数学背景时，以局部补充和向下追溯的方式解决，而不是提前完成整套数学预备课程。
>
> 每章同时包含理论与实践。实践的主要目的不是训练代码竞赛式编程能力，而是熟悉真实 AI 工作流程：环境、数据、模型、训练、实验、日志、评估、调试、模型保存、复现实验以及阅读现有代码库。

完成本课程后，应当能够：

   - 数据表示；
   - 模型架构；
   - 目标函数；
   - 训练方法；
   - 推理方法；
   - 数据与实验设计。
5. 能够使用 PyTorch 等现代框架完成标准训练流程，并阅读、运行和修改成熟开源项目。
6. 理解一个模型从论文公式到实际代码、训练任务和实验结果之间的完整链条。
7. 能够进行基本的模型复现、消融实验、超参数实验与结果分析。
8. 建立足够完整的知识框架，使后续可以直接进入具体论文方向，而不需要反复补大量基础概念。

# 第一章　学习系统与神经网络训练原理

这一章不是重新介绍“什么是机器学习”，而是建立整个课程共同使用的数学和计算框架。

## 核心内容

建立一个监督学习问题：
$$
\mathcal D=\{(\mathbf x_i,y_i)\}_{i=1}^{N}
$$
模型记为：
$$
f_{\boldsymbol\theta}:\mathcal X\rightarrow\mathcal Y
$$
训练的基本形式是经验风险最小化：
$$
\boldsymbol\theta^\ast
=
\arg\min_{\boldsymbol\theta}
\frac{1}{N}
\sum_{i=1}^{N}
\mathcal L
\left(
f_{\boldsymbol\theta}(\mathbf x_i),
y_i
\right)
$$

重点理解：

- 参数、输入、输出与状态的区别；
- forward pass；
- loss / objective；
- gradient；
- backward pass；
- optimizer；
- training 与 inference；
- mini-batch training；
- epoch、step、batch size；
- stochastic optimization。

分类问题中系统学习：

- logit；
- sigmoid；
- softmax；
- log-softmax；
- negative log-likelihood；
- cross entropy。

例如多分类：
$$
p(y=k|\mathbf x)
=
\frac{\exp(z_k)}
{\sum_j\exp(z_j)}
$$
交叉熵：
$$
\mathcal L
=
-\sum_k y_k\log p_k
$$

进一步进入计算图与反向传播。

理解链式法则如何作用于组合函数：
$$
\frac{\partial\mathcal L}{\partial\theta}
=
\frac{\partial\mathcal L}{\partial z}
\frac{\partial z}{\partial\theta}
$$

要求能够从数学意义解释 automatic differentiation，而不是把 `loss.backward()` 当成黑盒。

随后进入优化：

- Gradient Descent；
- SGD；
- Momentum；
- RMSProp；
- Adam；
- AdamW；
- learning rate；
- learning-rate scheduler；
- gradient clipping。

理解参数更新：
$$
\boldsymbol\theta_{t+1}
=
\boldsymbol\theta_t
-
\eta\nabla_{\boldsymbol\theta}\mathcal L
$$

以及 Adam 中一阶矩与二阶矩估计的意义。

## 数学重点

本章涉及：

- 多元微积分；
- gradient 与 Jacobian；
- chain rule；
- 概率分布；
- maximum likelihood；
- log-likelihood；
- entropy；
- cross entropy。

这些内容直接结合模型学习，不单独抽离成数学课程。

## 实践

使用 PyTorch 完整完成一个小型分类任务。

建议任务：

- MNIST / Fashion-MNIST；
- 或一个规模较小的表格分类数据集。

实践重点不是网络结构，而是完整训练流程：

```text
创建环境
→ 获取数据
→ Dataset / DataLoader
→ 定义模型
→ 定义 loss
→ 定义 optimizer
→ training loop
→ validation
→ 保存 checkpoint
→ 加载模型
→ inference
→ 分析错误样本
```

要求至少手写一次标准 training loop，而不是使用高级 Trainer 封装。

进一步实验：

- SGD 与 Adam 对比；
- 不同 learning rate；
- batch size 改变；
- 查看 loss curve；
- 人为制造训练失败并进行诊断。

最终应当能够解释一个 PyTorch 训练程序为什么按照这样的结构组织。

# 第二章　深度神经网络的核心结构机制

本章研究现代神经网络中几乎无处不在的内部机制。

这些机制比单独掌握某个模型更重要。

## 核心内容

首先重新认识 MLP：
$$
\mathbf h^{(l+1)}
=
\sigma
\left(
\mathbf W^{(l)}\mathbf h^{(l)}
+
\mathbf b^{(l)}
\right)
$$

重点不放在“全连接层是什么”，而是理解：

- depth；
- width；
- nonlinear representation；
- feature transformation；
- universal approximation 的基本意义。

随后系统研究 activation：

- sigmoid；
- tanh；
- ReLU；
- LeakyReLU；
- GELU；
- SiLU / Swish；
- GLU / SwiGLU。

研究初始化：

- Xavier initialization；
- He initialization；
- variance propagation；
- exploding / vanishing gradient。

进入 normalization：

Batch Normalization：
$$
\hat x
=
\frac{x-\mu_B}
{\sqrt{\sigma_B^2+\epsilon}}
$$

Layer Normalization：
$$
\hat x_i
=
\frac{x_i-\mu}
{\sqrt{\sigma^2+\epsilon}}
$$

进一步理解：

- BatchNorm；
- LayerNorm；
- RMSNorm；
- normalization 放置位置；
- train 与 inference 的区别。

重点研究 Residual Connection：
$$
\mathbf y
=
F(\mathbf x)+\mathbf x
$$

理解 residual learning 为什么使深层网络更容易优化，以及 residual connection 如何进入 Transformer、Diffusion、GNN 等现代架构。

其他内容包括：

- dropout；
- weight decay；
- early stopping；
- regularization；
- stochastic depth；
- parameter count；
- FLOPs 的基本概念。

## 数学重点

重点研究：

- 随机变量均值与方差传播；
- activation 对梯度的影响；
- Jacobian 连乘与梯度稳定性；
- residual mapping 的优化意义；
- $L_2$ regularization 与 weight decay 的区别。

## 实践

构建一个能够自由配置的 MLP：

```text
depth
width
activation
normalization
dropout
residual
```

进行控制变量实验。

例如：

- 2 层、10 层、50 层网络；
- 有无 residual；
- ReLU / GELU / SiLU；
- BatchNorm / LayerNorm / 无 normalization。

记录：

- training loss；
- validation loss；
- gradient norm；
- training speed；
- accuracy。

实践目标不是获得最佳成绩，而是观察“网络设计原则”如何真正影响训练。

# 第三章　表示学习与自监督学习

本章研究现代 AI 中最核心的概念之一：Representation Learning。

模型的主要作用不只是完成预测，而是学习数据的一种内部表示。

## 核心内容

Embedding：

给定离散对象 $x$，学习：
$$
x
\rightarrow
\mathbf e_x\in\mathbb R^d
$$

理解：

- embedding table；
- learned embedding；
- continuous representation；
- semantic geometry。

讨论：

- word embedding；
- token embedding；
- image embedding；
- node embedding；
- graph embedding；
- sample embedding。

进一步研究 latent representation：
$$
\mathbf z=f_{\boldsymbol\theta}(\mathbf x)
$$

理解：

- latent space；
- representation space；
- manifold；
- feature geometry；
- interpolation；
- disentanglement 的基本问题。

随后进入相似度学习：

点积：
$$
s(\mathbf x,\mathbf y)
=
\mathbf x^\top\mathbf y
$$

Cosine similarity：
$$
\operatorname{sim}(\mathbf x,\mathbf y)
=
\frac{\mathbf x^\top\mathbf y}
{\|\mathbf x\|\|\mathbf y\|}
$$

研究 Metric Learning 与 Contrastive Learning。

InfoNCE 类型目标：
$$
\mathcal L
=
-
\log
\frac{
\exp(\operatorname{sim}(\mathbf z_i,\mathbf z_i^+)/\tau)
}{
\sum_j
\exp(\operatorname{sim}(\mathbf z_i,\mathbf z_j)/\tau)
}
$$

进一步建立自监督学习的三类主要思想：

- predictive learning；
- masked modeling；
- contrastive learning。

典型方法包括：

- Word2Vec；
- SimCLR；
- BYOL；
- BERT；
- MAE；
- CLIP。

重点不是逐个学习模型，而是理解“监督信号从数据自身产生”的共同思想。

## 数学重点

重点研究：

- vector geometry；
- similarity measure；
- metric learning；
- entropy；
- mutual information 的基本思想；
- contrastive objective。

## 实践

完成一个简单 embedding learning 实验。

例如：

- CIFAR-10 + 简单 encoder；
- 使用 supervised contrastive learning 或 SimCLR 思路；
- 将数据映射到 embedding space。

然后：

```text
训练 encoder
→ 提取 embedding
→ PCA / UMAP 可视化
→ cosine similarity 检索
→ nearest-neighbor classification
```

实践重点在于第一次完整体验：

> 原始数据 → representation → representation space → downstream task

而不是只关注最终分类准确率。

# 第五章　Attention 与 Transformer

这是课程核心章节之一。

目标不是记住 Transformer 架构图，而是能够从矩阵运算推导并解释整个结构。

## 核心内容

从 Attention 开始。

给定：
$$
\mathbf Q=\mathbf X\mathbf W_Q,\qquad
\mathbf K=\mathbf X\mathbf W_K,\qquad
\mathbf V=\mathbf X\mathbf W_V
$$

Scaled Dot-Product Attention：
$$
\operatorname{Attention}
(\mathbf Q,\mathbf K,\mathbf V)
=
\operatorname{softmax}
\left(
\frac{\mathbf Q\mathbf K^\top}
{\sqrt{d_k}}
\right)
\mathbf V
$$

详细研究：

- Query；
- Key；
- Value；
- attention score；
- attention weight；
- self-attention；
- cross-attention；
- masking；
- causal attention；
- multi-head attention。

Multi-Head Attention：
$$
\operatorname{MHA}
(\mathbf Q,\mathbf K,\mathbf V)
=
\operatorname{Concat}
(\operatorname{head}_1,\ldots,\operatorname{head}_h)
\mathbf W_O
$$

然后构造完整 Transformer block。

研究：

- token embedding；
- positional encoding；
- self-attention；
- residual；
- normalization；
- feed-forward network；
- masking。

进一步区分：

- encoder-only；
- decoder-only；
- encoder-decoder。

对应典型模型：

- BERT；
- GPT；
- T5。

之后进入现代 Transformer 组件：

- Pre-Norm；
- RMSNorm；
- RoPE；
- SwiGLU；
- MQA；
- GQA；
- KV Cache；
- FlashAttention；
- long-context attention 的基本问题。

## 数学重点

重点包括：

- matrix multiplication；
- similarity matrix；
- softmax geometry；
- masking；
- positional representation；
- computational complexity。

Self-attention 典型复杂度：
$$
O(n^2d)
$$

要求理解复杂度来自何处，以及为什么长序列成为 Transformer 的主要工程问题。

## 实践

第一阶段：

从头实现一个最小 Self-Attention 与 Transformer block。

不依赖 `nn.Transformer`。

第二阶段：

完成一个 mini-GPT。

可以参考：

- minGPT；
- nanoGPT；
- Karpathy 的相关教学实现。

实践流程：

```text
文本数据
→ tokenizer
→ sequence batching
→ causal mask
→ Transformer
→ next-token loss
→ training
→ checkpoint
→ autoregressive generation
```

重点理解：

- 数据如何形成 batch；
- logits 如何变成 loss；
- causal mask 如何工作；
- generation loop 如何运行；
- temperature / top-k 如何改变输出。

这一章完成后，应能从模型结构、数学表达和代码三个层面解释 Transformer。

# 第六章　图神经网络

本章系统整理 GNN，并把已经接触过的内容提高到现代图学习框架。

## 核心内容

图：
$$
G=(V,E)
$$

节点特征：
$$
\mathbf X\in\mathbb R^{|V|\times d}
$$

邻接结构：
$$
\mathbf A\in\mathbb R^{|V|\times |V|}
$$

从 Message Passing Neural Network 统一理解 GNN：
$$
\mathbf m_v^{(l)}
=
\operatorname{AGGREGATE}
\left(
\{
\mathbf h_u^{(l)}
:
u\in\mathcal N(v)
\}
\right)
$$
$$
\mathbf h_v^{(l+1)}
=
\operatorname{UPDATE}
\left(
\mathbf h_v^{(l)},
\mathbf m_v^{(l)}
\right)
$$

重点模型：

- GCN；
- GraphSAGE；
- GAT；
- MPNN。

GCN 的典型形式：
$$
\mathbf H^{(l+1)}
=
\sigma
\left(
\tilde{\mathbf D}^{-\frac12}
\tilde{\mathbf A}
\tilde{\mathbf D}^{-\frac12}
\mathbf H^{(l)}
\mathbf W^{(l)}
\right)
$$

进一步研究：

- neighborhood aggregation；
- node classification；
- link prediction；
- graph classification；
- graph pooling；
- mini-batch graph training；
- neighborhood sampling。

现代问题：

- over-smoothing；
- over-squashing；
- positional / structural encoding；
- heterogeneous graph；
- graph transformer；
- geometric / equivariant network 的基本思想。

## 数学重点

包括：

- graph Laplacian；
- spectral 与 spatial 视角；
- permutation invariance；
- permutation equivariance；
- aggregation function；
- message passing expressivity。

可适当进入 Weisfeiler-Lehman test 与 GNN expressivity，但不作为纯理论专题长期停留。

## 实践

主要使用 PyTorch Geometric。

建议任务：

第一阶段：

Cora node classification。

完整经历：

```text
graph dataset
→ node features
→ edge_index
→ GCN
→ node-level loss
→ training
→ evaluation
```

第二阶段：

使用 GraphSAGE 或 GAT 替换 GCN。

第三阶段：

运行一个 graph classification 数据集。

重点学习 PyG 中真实图数据如何组织，而不是只手写公式。

最终理解：

- PyG Data；
- batching；
- message passing；
- neighborhood sampling；
- node-level 与 graph-level task 的工程区别。

# 第七章　概率生成模型与自回归建模

本章建立生成模型的统一框架。

目标是理解“学习数据分布”究竟意味着什么。

## 核心内容

判别模型通常研究：
$$
p(y|\mathbf x)
$$

生成模型进一步研究：
$$
p(\mathbf x)
$$
或：
$$
p(\mathbf x,\mathbf z)
$$

首先学习 Maximum Likelihood：
$$
\boldsymbol\theta^\ast
=
\arg\max_{\boldsymbol\theta}
\sum_i
\log p_{\boldsymbol\theta}(\mathbf x_i)
$$

然后建立几类重要生成模型。

### Autoencoder 与 VAE

Autoencoder：
$$
\mathbf z=f_{\boldsymbol\phi}(\mathbf x)
$$
$$
\hat{\mathbf x}=g_{\boldsymbol\theta}(\mathbf z)
$$

VAE 引入概率 latent variable：
$$
p_{\boldsymbol\theta}(\mathbf x,\mathbf z)
=
p(\mathbf z)
p_{\boldsymbol\theta}(\mathbf x|\mathbf z)
$$

ELBO：
$$
\log p_{\boldsymbol\theta}(\mathbf x)
\ge
\mathbb E_{q_{\boldsymbol\phi}(\mathbf z|\mathbf x)}
[
\log p_{\boldsymbol\theta}(\mathbf x|\mathbf z)
]
-
D_{\mathrm{KL}}
\left(
q_{\boldsymbol\phi}(\mathbf z|\mathbf x)
\|
p(\mathbf z)
\right)
$$

重点理解：

- approximate inference；
- KL divergence；
- reparameterization trick。

### GAN

研究：
$$
\min_G\max_D
\mathbb E_{\mathbf x\sim p_{\mathrm{data}}}
[\log D(\mathbf x)]
+
\mathbb E_{\mathbf z\sim p(\mathbf z)}
[
\log(1-D(G(\mathbf z)))
]
$$

理解：

- adversarial learning；
- discriminator；
- generator；
- mode collapse；
- min-max optimization。

GAN 不要求投入与 Diffusion 相同的学习时间，但其思想仍然重要。

### Autoregressive Modeling

利用概率链式分解：
$$
p(x_1,\ldots,x_T)
=
\prod_{t=1}^{T}
p(x_t|x_{<t})
$$

研究：

- teacher forcing；
- autoregressive generation；
- greedy decoding；
- beam search；
- temperature；
- top-k；
- top-p sampling。

这一部分直接连接后面的 LLM。

## 实践

实践一：

训练一个简单 VAE。

观察：

```text
input
→ encoder
→ latent distribution
→ sampling
→ decoder
→ reconstruction
```

可视化 latent space 和生成样本。

实践二：

使用已有小型 autoregressive model 进行 generation。

重点改变：

- temperature；
- top-k；
- top-p。

观察概率采样策略如何改变输出。

# 第八章　Diffusion、Score Model 与 Flow

这是生成模型部分的核心章节。

要求从概率过程、目标函数和模型训练三个层面真正掌握 Diffusion，而不是停留在“逐渐加噪再去噪”的描述。

## 核心内容

DDPM forward process：
$$
q(\mathbf x_t|\mathbf x_{t-1})
=
\mathcal N
\left(
\sqrt{1-\beta_t}\mathbf x_{t-1},
\beta_t\mathbf I
\right)
$$

记：
$$
\alpha_t=1-\beta_t
$$
$$
\bar\alpha_t
=
\prod_{s=1}^{t}\alpha_s
$$

可以直接得到：
$$
q(\mathbf x_t|\mathbf x_0)
=
\mathcal N
\left(
\sqrt{\bar\alpha_t}\mathbf x_0,
(1-\bar\alpha_t)\mathbf I
\right)
$$

因此：
$$
\mathbf x_t
=
\sqrt{\bar\alpha_t}\mathbf x_0
+
\sqrt{1-\bar\alpha_t}\boldsymbol\epsilon,
\qquad
\boldsymbol\epsilon\sim\mathcal N(\mathbf 0,\mathbf I)
$$

研究 reverse process：
$$
p_{\boldsymbol\theta}
(\mathbf x_{t-1}|\mathbf x_t)
$$

理解常见预测参数化：

- $\epsilon$ prediction；
- $x_0$ prediction；
- $v$ prediction。

典型训练目标：
$$
\mathcal L
=
\mathbb E_{
\mathbf x_0,t,\boldsymbol\epsilon
}
\left[
\|
\boldsymbol\epsilon
-
\boldsymbol\epsilon_{\boldsymbol\theta}
(\mathbf x_t,t)
\|_2^2
\right]
$$

进一步学习：

- DDPM；
- DDIM；
- U-Net；
- time embedding；
- conditioning；
- classifier guidance；
- classifier-free guidance；
- latent diffusion。

然后进入 Score Matching。

Score：
$$
\nabla_{\mathbf x}\log p(\mathbf x)
$$

理解 Diffusion Model 与 Score-Based Model 的联系。

最后进入 Flow Matching。

连续动力系统：
$$
\frac{d\mathbf x_t}{dt}
=
\mathbf v_{\boldsymbol\theta}
(\mathbf x_t,t)
$$

学习：

- continuous normalizing flow；
- probability path；
- vector field；
- flow matching；
- rectified flow。

最终形成：

```text
Diffusion
Score Model
SDE / ODE
Flow Matching
```

之间的整体联系。

## 数学重点

本章数学强度较高，包括：

- Gaussian distribution；
- conditional Gaussian；
- KL divergence；
- variational bound；
- stochastic process；
- Markov process；
- score function；
- ODE；
- SDE 的基本概念；
- vector field。

数学不回避，但只深入到能够理解现代生成模型论文所需的程度。
