# 第一章 · 第三部分（二）：Batch 反向传播与 PyTorch Autograd

## 1. 从单样本扩展到一个 Batch

上一轮我们有单个样本：
$$
\mathbf z
=
\mathbf W\mathbf x+\mathbf b
$$
其中：
$$
\mathbf x\in\mathbb R^n,\qquad
\mathbf W\in\mathbb R^{m\times n},\qquad
\mathbf b\in\mathbb R^m
$$

现在一次输入 $B$ 个样本。

为了与 PyTorch 常见约定一致，我们把每个样本放成一行，于是：
$$
\mathbf X\in\mathbb R^{B\times n}
$$
线性层写成：
$$
\mathbf Z
=
\mathbf X\mathbf W^\top+\mathbf 1\mathbf b^\top
$$
其中：
$$
\mathbf Z\in\mathbb R^{B\times m}
$$

这里：

- $\mathbf X$：整个 batch；
- $\mathbf W$：一套共享参数；
- $\mathbf b$：同一个偏置作用到 batch 中所有样本；
- $\mathbf Z$：所有样本的输出。

PyTorch 中：

```python
linear = nn.Linear(n, m)
z = linear(x)
```

若：

```python
x.shape == [B, n]
```

那么：

```python
z.shape == [B, m]
```

内部数学就是：
$$
\mathbf Z
=
\mathbf X\mathbf W^\top+\mathbf b
$$
其中偏置通过 broadcasting（广播）作用到每一行。

---

## 2. Batch Loss 如何变成一个标量

假设每个样本都有一个损失：
$$
L_1,L_2,\dots,L_B
$$
训练时通常取平均：
$$
L
=
\frac1B
\sum_{i=1}^{B}L_i
$$

所以虽然模型输出是一个批量张量，最终 backward 的起点仍然通常是一个标量：
$$
L\in\mathbb R
$$

这件事非常关键。

因为反向传播真正做的是：
$$
L
\rightarrow
\nabla_{\boldsymbol\theta}L
$$

如果定义：
$$
\mathbf G
=
\frac{\partial L}{\partial\mathbf Z}
\in\mathbb R^{B\times m}
$$
那么 $\mathbf G$ 可以理解为：

> batch 中每个样本、每个输出维度对最终总损失的贡献梯度。

接下来所有参数梯度都可以从它推出。

---

# 3. Batch 情况下线性层的三个梯度

前向传播：
$$
\mathbf Z
=
\mathbf X\mathbf W^\top+\mathbf 1\mathbf b^\top
$$

已知：
$$
\mathbf G
=
\frac{\partial L}{\partial\mathbf Z}
$$

我们分别求：

$$
\frac{\partial L}{\partial\mathbf W},
\qquad
\frac{\partial L}{\partial\mathbf b},
\qquad
\frac{\partial L}{\partial\mathbf X}
$$

### 对权重 $\mathbf W$

单个样本时：
$$
\frac{\partial L}{\partial\mathbf W}
=
\boldsymbol\delta\mathbf x^\top
$$

batch 情况下，要把所有样本的贡献累加。

结果是：
$$
\boxed{
\frac{\partial L}{\partial\mathbf W}
=
\mathbf G^\top\mathbf X
}
$$

检查尺寸：
$$
\mathbf G^\top
\in\mathbb R^{m\times B}
$$
$$
\mathbf X
\in\mathbb R^{B\times n}
$$
所以：
$$
\frac{\partial L}{\partial\mathbf W}
\in\mathbb R^{m\times n}
$$

与：
$$
\mathbf W\in\mathbb R^{m\times n}
$$
完全一致。

---

### 对偏置 $\mathbf b$

因为每个样本都使用同一个 $\mathbf b$，所以 batch 中所有样本的梯度要相加：
$$
\boxed{
\frac{\partial L}{\partial\mathbf b}
=
\sum_{i=1}^{B}\mathbf G_{i,:}
}
$$

写成矩阵形式：
$$
\boxed{
\frac{\partial L}{\partial\mathbf b}
=
\mathbf G^\top\mathbf 1
}
$$

如果 loss 本身采用 batch mean，那么 $\mathbf G$ 中通常已经包含了 $1/B$ 因子。

---

### 对输入 $\mathbf X$

为了继续把梯度传给前一层：
$$
\boxed{
\frac{\partial L}{\partial\mathbf X}
=
\mathbf G\mathbf W
}
$$

尺寸：
$$
\mathbf G\in\mathbb R^{B\times m}
$$
$$
\mathbf W\in\mathbb R^{m\times n}
$$
所以：
$$
\frac{\partial L}{\partial\mathbf X}
\in\mathbb R^{B\times n}
$$

于是 batch 版本的线性层 backward 可以压缩成：
$$
\boxed{
\begin{aligned}
\frac{\partial L}{\partial\mathbf W}
&=
\mathbf G^\top\mathbf X\\
\frac{\partial L}{\partial\mathbf b}
&=
\sum_{i=1}^{B}\mathbf G_{i,:}\\
\frac{\partial L}{\partial\mathbf X}
&=
\mathbf G\mathbf W
\end{aligned}
}
$$

这三个式子非常值得熟悉，因为以后你看到一个 `Linear` 层，就应该知道它反向传播时大致在做什么。

---

# 4. 两层 MLP 的 Batch Backprop

现在考虑：
$$
\mathbf Z_1
=
\mathbf X\mathbf W_1^\top+\mathbf b_1
$$
$$
\mathbf H
=
\phi(\mathbf Z_1)
$$
$$
\mathbf Z_2
=
\mathbf H\mathbf W_2^\top+\mathbf b_2
$$
最终：
$$
L
=
\mathcal L(\mathbf Z_2,\mathbf y)
$$

先定义：
$$
\mathbf G_2
=
\frac{\partial L}{\partial\mathbf Z_2}
$$

那么第二层：
$$
\frac{\partial L}{\partial\mathbf W_2}
=
\mathbf G_2^\top\mathbf H
$$
$$
\frac{\partial L}{\partial\mathbf b_2}
=
\sum_{i=1}^{B}\mathbf G_{2,i,:}
$$
继续传播：
$$
\frac{\partial L}{\partial\mathbf H}
=
\mathbf G_2\mathbf W_2
$$

经过激活函数：
$$
\mathbf G_1
=
\frac{\partial L}{\partial\mathbf Z_1}
=
\frac{\partial L}{\partial\mathbf H}
\odot
\phi'(\mathbf Z_1)
$$
也就是：
$$
\mathbf G_1
=
(\mathbf G_2\mathbf W_2)
\odot
\phi'(\mathbf Z_1)
$$

然后第一层：
$$
\frac{\partial L}{\partial\mathbf W_1}
=
\mathbf G_1^\top\mathbf X
$$
$$
\frac{\partial L}{\partial\mathbf b_1}
=
\sum_{i=1}^{B}\mathbf G_{1,i,:}
$$

如果还需要继续往前传：
$$
\frac{\partial L}{\partial\mathbf X}
=
\mathbf G_1\mathbf W_1
$$

整个流程就是：
$$
\mathbf Z_2
\rightarrow
\mathbf H
\rightarrow
\mathbf Z_1
\rightarrow
\mathbf X
$$

而每一层都同时做两件事：

1. 计算自己的参数梯度；
2. 把梯度继续传给前一层。

这就是深层网络反向传播的稳定重复结构。

# 5. PyTorch 中 `requires_grad` 到底控制什么

现在接到 PyTorch。

例如：

```python
import torch

x = torch.tensor([2.0], requires_grad=True)
w = torch.tensor([3.0], requires_grad=True)

y = w * x
loss = y ** 2
```

这里：

```python
requires_grad=True
```

表示：

> 这个张量参与的后续计算需要被自动微分系统跟踪，因为以后可能要计算相对于它的梯度。

执行：

```python
loss.backward()
```

之后：
```python
x.grad
w.grad
```
会保存：
$$
\frac{\partial L}{\partial x}
$$
和：
$$
\frac{\partial L}{\partial w}
$$

---

## 神经网络参数为什么自动有梯度

例如：

```python
layer = torch.nn.Linear(10, 5)
```

它内部的：
```python
layer.weight
layer.bias
```

都是 `Parameter` 对象。

`nn.Parameter` 默认：
```python
requires_grad=True
```

所以：

```python
loss.backward()
```

以后：

```python
layer.weight.grad
layer.bias.grad
```

就会存储相应梯度。

这就是优化器后来能够工作的原因。

# 6. `.grad` 为什么是“存储位置”而不是一个函数

很多初学者会把：

```python
parameter.grad
```

理解成“调用求梯度”。

其实不是。

`.grad` 更像一个容器。

例如：
```python
loss.backward()
```
执行后，PyTorch 把：
$$
\frac{\partial L}{\partial\mathbf W}
$$
计算出来，并写入：
```python
W.grad
```

所以：

```python
loss.backward()
```

负责计算。

```python
W.grad
```

负责存结果。

而：
```python
optimizer.step()
```

会读取这些 `.grad`，然后更新参数。

因此可以把 PyTorch 的训练关系写成：

```text
forward
↓
build computation graph
↓
loss.backward()
↓
write gradients into parameter.grad
↓
optimizer.step()
↓
read parameter.grad and update parameter
```

这三个步骤是分离的。

# 7. 为什么 PyTorch 的梯度默认会累加

假设：
```python
loss1.backward()
loss2.backward()
```
中间没有清空。

那么大致得到：
$$
\mathbf W.\text{grad}
=
\frac{\partial L_1}{\partial\mathbf W}
+
\frac{\partial L_2}{\partial\mathbf W}
$$

而不是只保存第二次梯度。

为什么设计成累加？

因为这允许很自然地实现：

- 一个参数参与多个计算分支；
- 多个 loss 联合优化；
- gradient accumulation（梯度累积）。

例如：
$$
L=L_1+L_2
$$
那么：
$$
\frac{\partial L}{\partial\theta}
=
\frac{\partial L_1}{\partial\theta}
+
\frac{\partial L_2}{\partial\theta}
$$

所以梯度累加在数学上非常自然。

标准训练中我们只是恰好希望每个 step 独立，因此要清空：

```python
optimizer.zero_grad()
```

或者更常见的现代写法：

```python
optimizer.zero_grad(set_to_none=True)
```

后者会把梯度设成 `None`，而不一定真的填充零张量，通常在性能和内存上更合适。

# 8. `detach()` 与 `no_grad()`：两种“停止追踪”的方式

这两个概念非常常见，而且容易混淆。

## `detach()`

假设：
```python
y = f(x)
```

正常情况下：
$$
x
\rightarrow
y
\rightarrow
L
$$
梯度可以从 $L$ 传回 $x$。

如果：
```python
z = y.detach()
```

那么 `z` 与 `y` 共享数值，但：
$$
\text{gradient path}
$$
在这里被切断。

概念上：
$$
x
\rightarrow
y
\quad\boxed{\text{STOP}}
\quad z
$$

后续如果：
$$
L=g(z)
$$
那么这个 loss 不会再通过 $z$ 回传到产生 $y$ 的前面计算。

`detach()` 常用于：

- teacher-student 模型；
- target network；
- 某些对比学习；
- reinforcement learning；
- 防止某条计算分支更新参数。

以后会大量见到。

---

## `torch.no_grad()`

例如：
```python
with torch.no_grad():
    pred = model(x)
```

含义是：

> 在这个上下文中的计算不要建立用于反向传播的自动微分图。

适合：

- validation；
- test；
- inference。

因为这些阶段通常根本不需要：
$$
\nabla_{\boldsymbol\theta}L
$$

所以没有必要保存反向传播需要的中间状态。

这可以显著减少显存占用。

---

## 两者区别

`detach()`：

> 对某个张量切断梯度传播路径。

`no_grad()`：

> 对一段代码关闭梯度记录。

这是不同层面的控制。

---

# 9. 为什么 `backward()` 后计算图通常会释放

考虑一次训练：

```python
pred = model(x)
loss = criterion(pred, y)
loss.backward()
```

为了 backward，forward 阶段必须保存许多中间信息。

但一旦反向传播完成，如果以后不再需要沿这条图求梯度，这些中间信息就没有继续保留的必要。

因此 PyTorch 默认会释放大部分用于 backward 的计算图资源。

所以如果你做：

```python
loss.backward()
loss.backward()
```

第二次通常会报错。

因为第一次 backward 之后，那条图已经被释放了。

如果确实需要在同一图上重复 backward，可以使用：

```python
loss.backward(retain_graph=True)
```

但这会增加内存占用，因此不能随便使用。

---

## 为什么训练下一步没有问题

因为每次新的 forward：
```python
pred = model(x)
loss = criterion(pred, y)
```
都会重新构建新的动态计算图。

所以训练过程实际上是：

```text
Step 1:
build graph
→ backward
→ free graph

Step 2:
build new graph
→ backward
→ free graph

Step 3:
...
```

PyTorch 这种机制称为 **dynamic computation graph（动态计算图）**。

也就是说，图是随着 Python 代码实际执行动态建立的。

这也是为什么 PyTorch 代码通常很自然：

```python
if condition:
    y = branch_a(x)
else:
    y = branch_b(x)
```

实际走哪条分支，就构建哪条计算图。

# 10. 一个值得亲手跑一次的最小实验

下面这个实验很适合验证你现在对 autograd 的理解：

```python
import torch

x = torch.tensor([2.0], requires_grad=True)
w = torch.tensor([3.0], requires_grad=True)
b = torch.tensor([1.0], requires_grad=True)

z = w * x + b
loss = z ** 2

loss.backward()

print("z =", z.item())
print("loss =", loss.item())

print("dx =", x.grad)
print("dw =", w.grad)
print("db =", b.grad)
```

手算：

$$
z=wx+b
$$

代入：
$$
z=3\times2+1=7
$$

损失：
$$
L=z^2=49
$$

所以：
$$
\frac{\partial L}{\partial z}
=
2z=14
$$

进一步：
$$
\frac{\partial z}{\partial w}=x=2
$$
因此：
$$
\frac{\partial L}{\partial w}
=
14\times2
=
28
$$

同理：
$$
\frac{\partial z}{\partial x}=w=3
$$
所以：
$$
\frac{\partial L}{\partial x}
=
14\times3
=
42
$$

以及：
$$
\frac{\partial L}{\partial b}
=
14
$$

因此 PyTorch 应得到：
```text
dx = 42
dw = 28
db = 14
```

这个实验很小，但已经完整包含：

- forward；
- computation graph；
- chain rule；
- backward；
- gradient storage。
