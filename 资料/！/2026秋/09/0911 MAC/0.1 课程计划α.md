## 一、我认为你现在最需要补的，不是更多模型，而是中间这一层

你现在的状态大致是：

> 简单 ML/DL 基础
> → 已经能直接进入 GNN、Diffusion 等现代模型
> → 也能开始读论文
> → 但大量“默认你已经知道”的中间层知识还没有形成完整体系。

例如：

* logits / softmax / cross-entropy
* embedding
* normalization
* residual connection
* sampling
* pooling
* masking
* loss 与 objective
* representation
* latent space
* autoregressive
* likelihood
* self-supervised learning
* contrastive learning
* fine-tuning
* pretraining
* calibration
* distribution shift

这些东西单独看都不难，但它们才是现代 AI 论文真正的“语法”。

所以课程不是：

> MLP → CNN → RNN → Transformer → GNN

这么简单。

而应该形成：

$$
\text{数据}
\rightarrow
\text{表示}
\rightarrow
\text{模型}
\rightarrow
\text{预测/生成分布}
\rightarrow
\text{目标函数}
\rightarrow
\text{优化}
\rightarrow
\text{泛化与评估}
$$

然后再看 Transformer、GNN、Diffusion、LLM，你会发现它们只是这套框架中的不同设计。

# 第一部分：神经网络真正是怎么工作的

这一部分我会把它作为整个课程最重要的地基层。

不是重新学“什么是神经网络”，而是把你以后看到的所有现代网络共同使用的机制补齐。

| 章  | 内容                  | 你最终应该掌握什么                                                    |
| -- | ------------------- | ------------------------------------------------------------ |

| 2  | Logit、概率与分类         | sigmoid、softmax、log-softmax、cross-entropy                    |
| 3  | 反向传播与计算图            | chain rule、backprop、autograd 到底在做什么                          |

# 第二部分：表示学习——现代 AI 最核心的思想之一

这一部分在传统课程中经常被拆散，但我会把它单独抽出来。

因为如果让我选一个现代 AI 最核心的词，我会选：

> Representation。

### 11. Embedding

重点不是“embedding 是一个向量”。

而是：

$$
x
\xrightarrow{f_\theta}
\mathbf{h}\in\mathbb{R}^d
$$

为什么要把现实对象变成向量？

什么叫：

* token embedding
* word embedding
* node embedding
* graph embedding
* image embedding
* patient embedding
* latent representation

以及为什么现代 AI 很大程度上是在学习“一个好的空间”。

---

### 12. Latent Space

把“隐空间”真正搞懂。

包括：

* latent variable
* latent representation
* manifold
* interpolation
* disentanglement
* representation geometry

这对 VAE、Diffusion、多模态、LLM 都非常重要。

---

### 13. 相似性、距离和 Metric Learning

掌握：

* Euclidean distance
* cosine similarity
* dot product
* triplet loss
* contrastive loss
* InfoNCE

你以后看到：

> 把相似样本拉近，不相似样本推远

就不再只是一个口号。

---

### 14. Self-Supervised Learning

这是现代 AI 必修。

主要研究三种思想：

**预测型**

例如预测下一个 token。

**Mask 型**

例如：

> BERT / MAE。

**Contrastive 型**

例如：

> SimCLR / CLIP。

这里会第一次把很多看起来毫无关系的模型统一起来。

# 第四部分：Attention → Transformer

## 18. Attention

先不讲 Transformer。

彻底解决：

$$
\mathbf{Q},\mathbf{K},\mathbf{V}
$$

到底是什么。

然后理解：

$$
\operatorname{Attention}(\mathbf Q,\mathbf K,\mathbf V)
=
\operatorname{softmax}
\left(
\frac{\mathbf Q\mathbf K^\top}{\sqrt{d_k}}
\right)\mathbf V
$$

重点研究：

* query
* key
* value
* similarity
* attention weight
* self-attention
* cross-attention
* masking
* multi-head attention

这一章值得单独学很多轮。

---

## 19. Transformer

> Embedding
> → Positional Encoding
> → Attention
> → Residual
> → LayerNorm
> → FFN
> → Residual
> → LayerNorm

之后区分：

* Encoder-only
* Decoder-only
* Encoder-decoder

即：

> BERT / GPT / T5

三种大范式。

## 24. Autoencoder 与 VAE

Autoencoder：

$$
x\rightarrow z\rightarrow\hat x
$$

再进入 VAE：

$$
p_\theta(x|z),\qquad q_\phi(z|x)
$$

理解：

* latent variable
* probabilistic encoder
* KL divergence
* ELBO
* reparameterization trick

这实际上是非常好的概率生成模型入门。

## 25. GAN

重点不是“GAN 很经典”。

$$
\min_G\max_D V(D,G)
$$

以及：

* generator
* discriminator
* adversarial training
* mode collapse
* distribution matching

顺便第一次认真认识 min-max optimization。

---

## 26. Autoregressive Model

这一章会连接生成模型与 LLM。

核心：

$$
p(x_1,\ldots,x_n)
=
\prod_{i=1}^{n}
p(x_i|x_{<i})
$$

然后讨论：

* teacher forcing
* sampling
* temperature
* greedy
* top-k
* top-p

你之前接触的 sampling 在这里会真正归位。

# 另一方面，有三个“隐形副线”会始终存在

第一是数学。

不会单独先让你学完一套概率论、优化、线代再开始 AI，而是遇到时补。例如 Diffusion 遇到 Gaussian，就补多元高斯；Attention 遇到矩阵映射，就补相应线代；VAE 遇到 KL divergence，就把 KL 真正讲明白。

第二是 PyTorch。

不专门开一门“PyTorch 教程”，但随着课程推进，你应该逐渐能读：

```python
x = self.embedding(x)
x = self.attn(x)
x = x + residual
x = self.norm(x)
loss.backward()
optimizer.step()
```

最终能够从论文结构对应到代码结构。

第三是论文。

每学完一个重要模型家族，至少应该读一篇真正具有代表性的论文。例如 Transformer、ResNet、GNN、VAE、Diffusion、CLIP 等。

不是为了“刷论文”，而是逐渐让：

> 教科书知识

和

> 论文语言

接轨。

而结合你现在的情况，我尤其建议不要马上继续横向收集几十种模型。下一阶段最值得正式开课的是前面的“神经网络核心机制”，把 loss、backprop、optimizer、normalization、residual、embedding 这一整层打通。打通以后，你正在学的 GNN、Diffusion，以及之后的 Transformer / LLM，会突然变得比现在规整很多。
